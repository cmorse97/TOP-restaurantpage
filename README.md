# Mock Restaurant Website

A simple, multi-page mock restaurant website built with HTML, CSS, and JavaScript, leveraging Webpack as a module bundler and utilizing JavaScript modules and classes for a structured and organized codebase.

## Overview

This project demonstrates the use of Webpack to manage and bundle assets, as well as the implementation of JavaScript modules and classes to create a dynamic, single-page application (SPA)-like experience. The website features three main pages: Home, Menu, and About, each with its own dedicated module responsible for rendering its content. Navigation between these pages is handled dynamically through DOM manipulation, updating a designated 'content' area without requiring full page reloads.

## Technologies Used

- **HTML:** Provides the basic structure and elements of the website.
- **CSS:** Styles the website, ensuring a visually appealing and consistent user interface.
- **JavaScript:** Implements the dynamic behavior, including page rendering and navigation, using ES6 modules and classes.
- **Webpack:** A module bundler used to compile JavaScript modules, manage dependencies, and bundle assets for efficient deployment.

## Project Structure

The project is organized with the following key files and directories:

```
├── dist/

│ └── index.html # Bundled HTML output by Webpack
├── src/

```

## Key Concepts Demonstrated

- **Webpack:** Configuration and usage for bundling JavaScript modules and potentially CSS.
- **JavaScript Modules (ES6):** Utilizing `import` and `export` syntax to organize code into reusable and maintainable modules for each page.
- **JavaScript Classes:** Implementing classes within each page module (e.g., `HomePage`, `MenuPage`, `AboutPage`) to encapsulate the logic for creating and rendering the HTML content for that specific page.
- **Dynamic DOM Manipulation:** JavaScript dynamically clears the content of a designated HTML element (e.g., a `<div id="content">`) and renders the HTML structure generated by the active page's class.
- **Single-Page Application (SPA) Navigation:** Simulating navigation between different sections of the website without full page reloads, providing a smoother user experience.

## How to Run

1.  **Clone the repository:**
    ```bash
    git clone git@github.com:cmorse97/TOP-restaurantpage.git
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Build the project with Webpack:**
    ```bash
    npm run build
    ```
    This command will use the `webpack.config.js` file to bundle your JavaScript modules into `dist/main.js`.
4.  **Open `dist/index.html`** in your web browser.

    _(Note: For a more development-friendly experience with live reloading, you might have a development server configured in your `package.json` scripts, which you can run with `npm run start` or a similar command. Refer to your `package.json` file for available scripts.)_

## Code Structure Details

- **`src/home.js`, `src/menu.js`, `src/about.js`:** Each of these files contains a JavaScript class (e.g., `HomePage`) responsible for creating the HTML structure for their respective pages. These classes likely have a `render()` method that generates the necessary DOM elements.
- **`src/index.js`:** This is the main JavaScript file. It imports the classes from the individual page modules. It contains the logic for:
  - Selecting navigation elements (e.g., buttons or links).
  - Attaching event listeners to these navigation elements.
  - When a navigation event occurs, it:
    - Clears the content of the designated 'content' area in the DOM.
    - Instantiates the appropriate page class.
    - Calls the `render()` method of that class to dynamically generate and append the page's HTML content to the 'content' area.
- **`webpack.config.js`:** This file configures how Webpack should bundle your JavaScript modules and any other assets. It specifies the entry point (`src/index.js`), the output path (`dist/main.js`), and any necessary loaders or plugins.
